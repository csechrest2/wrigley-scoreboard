WRIGLEY FIELD SCOREBOARD — Phase 2
===================================

SETUP:
1. Copy your Frank.ttf font file into this folder (same level as index.html)
2. Open index.html in Chrome or Firefox
3. The scoreboard will automatically pull live MLB data

FILES NEEDED IN THIS FOLDER:
  index.html
  scoreboard_base.png
  clock_face.png
  clock_hand_hour.png
  clock_hand_minute.png
  Frank.ttf              ← copy from your system fonts

OBS USAGE:
  Add browser source → URL: file:///path/to/index.html?obs=1
  Width: 1402, Height: 1057
  Check "Shutdown source when not visible"

REFRESH RATE: Every 30 seconds (live games)
